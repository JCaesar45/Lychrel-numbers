Methodology

How the instrument works.

Precision is not negotiable. Every arithmetic operation is performed on strings — never on JavaScript's native Number type, which silently corrupts integers beyond 2 53 − 1.

01
Reverse the digits

The current value is treated as a string. Reversal is a character-level operation — no numeric parsing, no precision loss.

02
Add digit by digit

A manual addition routine walks both strings right-to-left, propagating carry values exactly as taught in primary school. Arbitrary length supported.

03
Test for palindrome

Two pointers advance from both ends toward the center. The first mismatch aborts the check. If they cross without finding one, we have a palindrome.

04
Repeat or conclude

If a palindrome is found, the number is not Lychrel. If five hundred iterations pass without one, the number is declared a Lychrel candidate.
